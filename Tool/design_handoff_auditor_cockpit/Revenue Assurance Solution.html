2 · How It Works

Eight specialised agents for a continuous, agentic assurance layer

Phase 1
Agent 01Live AI Insights

Real-time analysis cards on the dashboard: "Cards exceptions up 40% — driven by new annual fee not yet repriced."

Replaces hardcoded static dashboard strings with continuously updated, contextual analysis.
Phase 1
Agent 02Exception Clustering

Groups hundreds of raw exceptions into a handful of root-cause clusters by pattern, product, and timing.

Today: auditors spend 2 days sorting before any real investigation begins.
Phase 1
Agent 03Scoring & Narrative

Ranks clusters by financial materiality. Drafts the plain-English explanation for each in the auditor's voice.

Today: manual writing-up of findings consumes more time than the investigation itself.
Phase 1
Agent 04Dashboard Chat

"Show me all Trade Finance exceptions over ₹50L in March." "Why is the Cards backlog growing?" Natural-language access.

Removes the dashboard navigation barrier. Auditors get answers in seconds, not clicks.
Phase 2
Agent 05Precedent Surfacing
RAG

Retrieves prior rulings on similar exceptions. "This waiver was disputed in Q2 — here's how it was resolved."

Inconsistent rulings on similar cases create regulatory audit risk. This makes decisions auditable.
Phase 2
Agent 06Month-End Narrative

Today: 1–2 days of senior auditor time monthly. Becomes a review-and-approve workflow.

Today: manual chasing in spreadsheets — exceptions sit open for weeks without follow-up.

Reviews triaged clusters and precedents; approves owner mails the agent drafted
Process Owner
Receives the agent-drafted mail; confirms or disputes the exception

8 · The Build Plan

Developing the Phase 1 MVP  ·  scope: 5 charges · dashboard · 3 agents · chat  ·  3 weeks total

Week 1Data foundation
Pick 5 charges from KPMG list (start simple: Cards annual fee, late fee, FX markup, loan processing fee, swift charges)
Read those 5 SQL scripts · identify source tables and columns needed
Vibe-code synthetic data generator in Python (Faker + pandas) — match Finacle/Finone column shapes
Load to Supabase Postgres · ~10K transactions per charge type · run KPMG scripts → confirm exceptions surface
ModeVibe + Traditional
Week 1Rule engine + exception store
Python wrapper to execute the 5 SQL scripts on schedule (APScheduler) · log every run
Exception store schema: rule_id, txn_id, expected, actual, delta, status, cluster_id · idempotent writes
FastAPI backend: /rules, /exceptions, /clusters endpoints · /healthz · JSON only · no auth (single demo user)
Smoke test: each rule produces deterministic exceptions on the synthetic data
ModeTraditional
Week 2Three agents
Clustering agent: embed narratives (text-embedding-3-small) → HDBSCAN in Python · stable cluster IDs
Scoring & Narrative agent: Claude Sonnet 4.6 via Anthropic SDK · prompt = cluster + 5–20 examples + materiality · structured JSON output
Dashboard Chat agent: tool-use loop with 4 tools (query_exceptions, get_cluster, leakage_summary, rule_status) · streaming
Test each agent on 20 hand-crafted scenarios · add prompt caching headers (cuts API spend ~70%)
ModeVibe + Traditional
Week 3Dashboard + Live AI Insights
Next.js 15 app · shadcn/ui · Tailwind · 3 pages: Dashboard, Exceptions, Chat
Dashboard: KPI cards (leakage detected, recovered, pending) · trend chart (Recharts) · cluster list
Live AI Insights: Claude generates 3 one-line insights from current data every 6 hours · cached in Postgres
Exceptions: cluster view → drill-down · narrative · approve/dispute (no-op for demo) · Chat: streaming with tool-call indicators
Deploy frontend to Vercel · backend to Railway · custom domain (optional)
ModeVibe Coding
Week 3Polish & demo prep
Seed a realistic demo scenario: new credit card variant → 400 exceptions → 1 dominant cluster → ₹2.4 Cr material
Record 5-min Loom walkthrough using the credit card variant story
Write README · simple architecture diagram · cost breakdown · setup instructions
End-to-end test · fix obvious gaps · password-protect dashboard for demos
ModePolish
Done when: demo runs end-to-end on synthetic data · 3 agents return sensible output · dashboard + chat live on a URL · 5-min Loom recorded.
Total API spend: ~$80–250 · Claude Code Pro $20/mo × 3 = $60
